## ⚙️ TECHNIQUE (Comment ça marche)

**1. SVG = Généré dynamiquement**
```javascript
// Chaque variation est définie en JavaScript
const svgDefinitions = {
  fullcolor: `<svg>...</svg>`,
  monochrome: `<svg>...</svg>`,
  // etc.
}

// Download = Create Blob + trigger download
function downloadSVG(variant) {
  const svg = svgDefinitions[variant];
  const blob = new Blob([svg], { type: 'image/svg+xml' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `genesis-logo-${variant}.svg`;
  a.click();
}
```

**2. PNG = SVG → Canvas → PNG**
```javascript
// Convert SVG to PNG via Canvas API
function downloadPNG(variant, size) {
  const svg = svgDefinitions[variant].replace('SIZE', size);
  const canvas = document.createElement('canvas');
  canvas.width = size;
  canvas.height = size;
  
  const img = new Image();
  img.onload = () => {
    ctx.drawImage(img, 0, 0, size, size);
    canvas.toBlob(blob => {
      // Trigger download
    });
  };
  img.src = 'data:image/svg+xml;base64,' + btoa(svg);
}
```

**3. ZIP = JSZip library**
```javascript
// Create ZIP with all assets
async function downloadCompletePackage() {
  const zip = new JSZip();
  
  // Add SVGs
  const svgFolder = zip.folder('SVG');
  for (const [variant, svg] of Object.entries(svgDefinitions)) {
    svgFolder.file(`genesis-logo-${variant}.svg`, svg);
  }
  
  // Generate PNGs (all sizes × all variants)
  const pngFolder = zip.folder('PNG');
  for (const variant in svgDefinitions) {
    for (const size of [256, 512, 1024, 2048]) {
      const blob = await createPNGBlob(variant, size);
      pngFolder.file(`genesis-logo-${variant}-${size}px.png`, blob);
    }
  }
  
  // Download ZIP
  const content = await zip.generateAsync({ type: 'blob' });
  saveAs(content, 'genesis-brand-assets-complete.zip');
}
```

**Pour Web (Portal) :**
```tsx
// app/layout.tsx
export default function RootLayout({ children }) {
  const [showSplash, setShowSplash] = useState(true);
  
  useEffect(() => {
    const timer = setTimeout(() => setShowSplash(false), 6000);
    return () => clearTimeout(timer);
  }, []);
  
  if (showSplash) {
    return <SplashScreen />;
  }
  
  return children;
}
```

**Pour Mobile (OVYON) :**
```tsx
// App.tsx (React Native)
import { SplashScreen } from './components/SplashScreen';

export default function App() {
  const [ready, setReady] = useState(false);
  
  useEffect(() => {
    setTimeout(() => setReady(true), 6000);
  }, []);
  
  if (!ready) return <SplashScreen />;
  return <MainApp />;
}
```

**1. Reconnaissance instantanée**
- Logo central = focus unique

- Animations fluides (cubic-bezier pro)

- Pure CSS animations (pas de JS heavy)

- **Confiance** : Animations stables, prévisibles
- **Sophistication** : Subtilité des effets
