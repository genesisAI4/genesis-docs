### 🎨 Design Philosophy

**Inspiré du Logo Genesis :**
```
Logo Genesis          →    Nexus Character
─────────────────────────────────────────────
Brackets ([ ])        →    Antennes sur tête
Core carré bleu       →    Corps robot
Pupil central         →    Cœur lumineux (core accent)
Couleur #3B82F6       →    Couleur principale
Guardian brackets     →    Mode protection
```

**Mais avec Personnalité :**
```
+ Bras articulés (peuvent bouger indépendamment)
+ Jambes avec pieds (peut marcher, sauter)
+ Yeux expressifs (rectangles qui changent)
+ Émotions (vert=content, rouge=alerte, bleu=neutre)
+ Accessories (clavier, cœurs, question mark, Zzz)
```

## 💻 INTÉGRATION DANS TES PROJETS

### Genesis Portal (Web)
```tsx
// components/LogoAnimated.tsx
export function LogoAnimated({ animation = 'eternal-pulse' }) {
  return (
    <svg className={`anim-${animation}`} width={120} height={120}>
      {/* SVG from download */}
    </svg>
  );
}

// components/Nexus.tsx
export function Nexus({ pose = 'default', animated = false }) {
  const className = animated ? 'nexus-anim-idle' : '';
  return (
    <svg className={className} width={80} height={80}>
      {/* SVG from download */}
    </svg>
  );
}

// Usage examples:
// Hero section
<LogoAnimated animation="quantum-float" />

// Loading screen
<LogoAnimated animation="neural-sync" />

// Onboarding welcome
<Nexus pose="wave" animated />

// Success message
<Nexus pose="happy" animated />

// Error page
<Nexus pose="confused" />
```

### Genesis Companion (Electron)
```typescript
// Splash screen
<LogoAnimated animation="zenith-bloom" />

// Tray icon (statique)
tray.setImage('nexus-default.png')

// Notification
showNotification({
  title: 'Guardian Mode Active',
  icon: 'nexus-alert.png',
  body: 'Review required'
});
```

### OVYON Mobile (React Native)
```tsx
// Animated Logo (Lottie ou SVG)
<LottieView source={require('./animations/logo-pulse.json')} />

// Mascotte dans onboarding
<Image source={require('./nexus/wave.png')} />
```

### Extension (Popup)

## 🎨 CAS D'USAGE PAR CONTEXTE

### Onboarding Flow
```
Page 1: Welcome
  Logo: Zenith Bloom (majestueux)
  Nexus: Wave (accueil)
  
Page 2: Features
  Logo: Eternal Pulse (background)
  Nexus: Thumbs Up (approbation)
  
Page 3: Setup
  Logo: Neural Sync (processing)
  Nexus: Working (configuration)
  
Page 4: Done!
  Logo: Sovereign Aura (triumph)
  Nexus: Happy (celebration)
```

### Workflow Execution
```
State: Idle
  Logo: Wave Harmony
  Nexus: Default (attente)

State: Processing
  Logo: Quantum Float
  Nexus: Working/Thinking

State: HITL Needed
  Logo: (pause animation)
  Nexus: Guardian (amber, alerte)

State: Success
  Logo: Zenith Bloom
  Nexus: Thumbs Up

State: Error
  Logo: (stop)
  Nexus: Alert (rouge)
```

### Chat Interface
```
User typing:
  Nexus: Idle Breathing (écoute)

AI processing:
  Logo: Neural Sync (header)
  Nexus: Thinking (animation)

Response ready:
  Nexus: Default + typing animation (écrit réponse)

Message sent:
  Nexus: Thumbs Up (confirmation)
```
