## 🚀 USAGE

**Pour Electron (Companion) :**
```javascript
// main/index.ts
const splash = new BrowserWindow({
  width: 800,
  height: 600,
  frame: false,
  transparent: true,
  alwaysOnTop: true
});

splash.loadFile('splash.html');

setTimeout(() => {
  splash.close();
  mainWindow.show();
}, 6000);
```

**Pour Web (Portal) :**
```tsx
// app/layout.tsx
export default function RootLayout({ children }) {
  const [showSplash, setShowSplash] = useState(true);
  
  useEffect(() => {
    const timer = setTimeout(() => setShowSplash(false), 6000);
    return () => clearTimeout(timer);
  }, []);
  
  if (showSplash) {
    return <SplashScreen />;
  }
  
  return children;
}
```

**Pour Mobile (OVYON) :**
```tsx
// App.tsx (React Native)
import { SplashScreen } from './components/SplashScreen';

export default function App() {
  const [ready, setReady] = useState(false);
  
  useEffect(() => {
    setTimeout(() => setReady(true), 6000);
  }, []);
  
  if (!ready) return <SplashScreen />;
  return <MainApp />;
}
```

## 💡 POURQUOI CE DESIGN FONCTIONNE

**1. Reconnaissance instantanée**
- Logo central = focus unique
- Pas de distraction textuelle
- Branding mémorable

**2. Perception de qualité**
- Animations fluides (cubic-bezier pro)
- Timing précis (pas trop long, pas trop court)
- Effets subtils (breathing, glow)

**3. Performance**
- Pure CSS animations (pas de JS heavy)
- Pas de requêtes externes (SVG inline)
- Load quasi instantané

**4. Émotions évoquées**
- **Confiance** : Animations stables, prévisibles
- **Sophistication** : Subtilité des effets
- **Souveraineté** : Logo fort, centré, breathing (vie)
