# Companion - Installation

Guide d'installation de Genesis Companion.

---

## 📋 Prérequis

| Outil | Version |
|-------|---------|
| **Node.js** | 20+ |
| **PNPM** | 8+ |

---

## 🚀 Installation

### 1. Cloner

```bash
git clone https://github.com/genesisAI4/genesis-companion.git
cd genesis-companion
```

### 2. Installer

```bash
pnpm install
```

### 3. Démarrer

```bash
pnpm dev
```

---

## ⚙️ Configuration

### .env

```bash
NODE_ENV=development
COMPANION_PORT=5174
NEXUS_URL=ws://localhost:8080
```

---

**Temps estimé :** 5 minutes
