**Genesis Documentation** est le centre de connaissance officiel de l'écosystème. Elle contient les guides d'architecture, les références API, les tutoriels de création d'agents et les rituels de contribution communautaire.

---

## 🧬 L'Organisme Genesis
La Documentation occupe le rôle de **Mémoire Collective / Grimoire** dans l'organisme Genesis. Elle est classée en **TIER 1 — COMMONS**.

- **Rôle Vital** : Éducation, onboarding, standardisation technique et transparence architecturale.
- **Philosophie** : La souveraineté exige que l'utilisateur comprenne ses outils. Nous offrons le savoir gratuitement pour permettre une adoption massive en Afrique et dans le monde.

---

## 🏗️ Structure & Contenu

### 1. Guides d'Architecture
Explications détaillées sur le protocole **A2A**, le moteur de risque **Guardian**, le coffre-fort **Vault** et l'exécution durable via **Temporal**. Indispensable pour comprendre comment les organes communiquent.

### 2. Référence API & SDK
Documentation générée automatiquement pour tous les endpoints du Cloud API et les méthodes des différents SDKs (Python, TypeScript, Go). Chaque fonction est documentée avec des exemples clairs.

### 3. Parcours d'Apprentissage
- **Niveau Novice** : Installer et configurer son premier Nexus.
- **Niveau Créateur** : Développer un workflow Igon-7 et le publier sur la Marketplace.
- **Niveau Architecte** : Construire des tentacules custom et intégrer des hardwares complexes.
